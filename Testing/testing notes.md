# 手動探索測試
## 測試框架
### 等價劃分 (Equivalence class partitioning)
適用情境: 探索測試、單元測試、時間、狀態
1. 將輸出分成正向、反向
2. 將輸入分成等價類別群組
3. 對每一個等價類別群組，選擇一個代表/範例來測試
4. 反向至少會有負數、文字、符號

### 邊值分析 (Boundary value analysis)
適用情境: 找出定義、邏輯的錯誤狀況
1. 以等價劃分為基礎
2. 找出每個群組的邊界值

### 狀態轉移 (State transition)
適用情境: 輸入值歷史會改變狀態、行為
1. 使用樹狀圖 (tree diagram) 來呈現狀態轉移

### 決策表 (Decision table)
適用情境: 輸入值之間具有邏輯關聯，e.g.: AND、OR
1. 整理所有可能的測試組合(輸入、輸出)
2. 將輸入拆分為正向、反向條件
3. 將輸出拆分為正向、反向結果
4. 填入決策表，每一組代表一個測試案例 
5. 檢視不必要的條件，減少測試案例數量
